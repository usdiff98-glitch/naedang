# 내당한우 website — agent notes

Static Astro 7 + Tailwind v4 one-page site in Korean. See README.md for the full overview.

## Development

- `npm run dev` serves on port 4327 (runs `npm run fonts` first). To keep a server running in the
  background, run `npm run fonts && npx astro dev --background` and manage it with
  `astro dev stop | status | logs`.
- Before committing: `npm run check` (0 errors expected) and `npm run build`.
- UI checks against a running server: `npm run check:overflow -- <url>` and
  `npm run screenshots -- <url> <outDir>` (set `CHROME_PATH` if Playwright's Chromium is not installed).

## Content rules (strict)

- Facts live only in `src/data/restaurant.ts`, and each one must be backed by `docs/research.md`.
  Never invent prices, weights, grades, awards, history, dates or quotes.
- Never claim 1++ grade, 암소, 홍성한우 brand certification, "서산 목장", a founding year, or free parking.
  All of these are unconfirmed.
- Menu prices are the Naver Place menu of 2026-04-16. Liquor prices (2019) are intentionally omitted.
- Quotes must be the owner's own words (Naver Place introduction or the old homepage), captioned as such.
- Keep on-page text minimal (the owner's request): the 內堂 mark and name, short section titles, menu
  names with weights and prices, hours/break/holidays, address, phone, a one-line reservation note and
  map links. No descriptive paragraphs, intro prose, long captions or quotes; let photos carry the mood.
- Any text that is needed stays short and plain Korean (label style or "~요"), with no literary words
  (빚어낸, 품격, 정수, 여정, 선사, 한 채), em dashes or slogan fragments.

## Images

- Only `naver_biz_*` photos (the owner's Naver Place uploads) may appear on the site. `visitor_blog_*`
  photos are copyrighted by bloggers: never copy, import or reference them.
- Add photos with `node scripts/prepare-photos.mjs <images-dir>` (strips EXIF/GPS) and render them
  through `src/components/Photo.astro` so they get WebP `srcset`, lazy loading and the reveal effect.
- Where no photo exists (e.g. the interior), use illustration or typography. Never use stock photos or
  AI-generated images.

## Fonts

- `src/styles/fonts.css` and `public/fonts/` are generated by `scripts/build-fonts.mjs`. Do not edit
  them by hand. The subset covers the characters found in `src/`, so rerun the script after copy changes
  (dev and build already do).
- The 內 and 堂 glyphs are vector paths in `src/data/glyphs.ts`, so the hero wordmark renders without
  waiting for a font.
